# Executive Priority Mapper

This tool is used to assess executive priorities related to risk, cost, reliability,
and accountability, and to translate those priorities into implied ownership domains
within the IT operating model.

The output is intended to support leadership alignment discussions and does not
prescribe organizational structure or headcount decisions.

## Usage

1. Install Python 3.10+
2. Create and activate a virtual environment
3. Install dependencies:
   pip install -r requirements.txt
4. Run the application:
   streamlit run app.py

## Output

The application produces:
- Role implication scores
- Visual summaries for discussion
- Exportable CSV artifacts

This tool is intended for internal use.
